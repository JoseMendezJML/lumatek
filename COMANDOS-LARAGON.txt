LUMATEK - COMANDOS DE INSTALACIÓN

1) Coloca la carpeta en:
   C:\laragon\www\Lumatek

2) Abre la terminal de Laragon:

   cd C:\laragon\www\Lumatek
   composer install
   copy .env.example .env
   php artisan key:generate

3) Crea la base "lumatek" en HeidiSQL.
   Puedes ejecutar database\heidisql_create_database.sql

4) Después ejecuta:

   php artisan migrate --seed
   php artisan optimize:clear

5) Abre:
   http://lumatek.test

   O ejecuta:
   php artisan serve
